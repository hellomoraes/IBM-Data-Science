# Tools for Data Science

This course offers a beginner-friendly overview of the most commonly used programming languages in data science. It also introduces essential tools like Jupyter Notebooks, Watson Studio, and GitHub, which will be used throughout the upcoming courses.

# 🔑 Key Skills Learned

- Overview of Data Science Tools
- Programming Languages for Data Science (Python, R, SQL, Java, Scala, C++, JavaScript, Julia)
- Libraries, APIs, Datasets, and Models
- Jupyter Notebooks and JupyterLab
- RStudio and GitHub
- IBM Tools for Data Science
